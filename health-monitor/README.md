# Health Monitor V1

An early Bash system monitoring tool I built while learning Linux.

## Features

- System information
- CPU information
- Memory information
- Running processes
- Disk usage
- Disk health checks
- Memory health checks
- Executable file counting
- Basic logging
- Configurable health thresholds

This is an early learning project and represents an earlier stage of my Linux/Bash development.
